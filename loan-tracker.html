One-time setup (do this once, share the same values with your friend):
  1. Go to console.firebase.google.com → Add project (skip Analytics).
  2. Left menu → Build → Realtime Database → Create Database → choose a location → start in test mode.
  3. Project settings (⚙) → General → scroll to Your apps → Web (</>) → register → copy the firebaseConfig = {…} block.
  4. Paste it below. Pick any room code and give your friend the same config + room code.

Privacy: anyone with your config + room code can read/write the data. Use a hard-to-guess room code. Fine for lunch money; don't store secrets.
